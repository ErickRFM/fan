# FanForge — ASUS VivoBook M3500QC

Aplicación Windows 11 (C#/.NET 8) para investigar y solicitar control manual de ventiladores ASUS por interfaces OEM. **Prototipo sin validación física.**

> ⚠️ No está demostrado que el firmware M3500QC acepte el control PWM externo. No se distribuyen DLL ni controladores propietarios de ASUS. El modo manual requiere confirmación mediante RPM reales; conserva la restauración a BIOS.

El código fuente y pruebas están siendo incorporados en la rama de implementación. Revisa `docs/HARDWARE-TEST.md` antes de utilizarlo en hardware real.

Se basa en las exportaciones documentadas por [AsusFanControl](https://github.com/Karmel0x/AsusFanControl) (MIT). No afiliado a ASUS.
